# Incident Response Reports

This directory contains incident investigation reports based on the **NIST Incident Response Framework**. 

The main file, `Multiple-Incident Response Report`, detailed analyses for each incident, including:
- **Lessons Learned:** Key takeaways from the investigation.
- **Root Cause & Prevention:** Recommendations on how the incident could have been prevented.
- **Mitigation & Future Controls:** Actionable measures to prevent similar incidents from occurring in the future.
