# Wazuh SOC Home Lab - Project 1: SIEM Deployment

**Project Goal:** Deploy a fully functional open-source SIEM (Wazuh) in a VMware Ubuntu lab to gain hands-on experience in SOC monitoring and alert management.

**Skills Demonstrated:**
- SIEM deployment & configuration
- Agent management
- Dashboard navigation
- Basic log analysis

**Tools Used:**  
Wazuh 4.14 (All-in-One), VMware Workstation, Ubuntu 24.04 LTS
