3. Wazuh SOC Home Lab - Project 3: Simulate Attacks + Detect in Wazuh (Brute Force, Scans, File Tampering)

Project Goal: Simulate real-world attacks (Brute Force SSH, Port Scanning, and File Tampering) from a Kali Linux attacker VM, create custom detection rules in Wazuh, and perform alert triage to strengthen threat detection and incident response skills.

Skills Demonstrated:
- Red Team attack simulation using Hydra and Nmap
- Custom rule creation and tuning in Wazuh
- Brute force detection and MITRE ATT&CK mapping (T1110)
- Alert triage, log correlation, and incident investigation
- Building realistic SOC detection workflows

Tools Used:  
Wazuh 4.14 (All-in-One), Kali Linux, Hydra, Nmap, VMware Workstation, Ubuntu 24.04 LTS
